CONTENTS is graded three ways, as the authorization requires:
  PI   full policy targets (visit distributions) -- what AlphaZero training needs
  EXP  expert moves (a chosen move, no distribution)
  BARE bare game histories (move sequence only)

CAN SGF CARRY PI? YES -- and an earlier draft claimed otherwise.
------------------------------------------------------------------------------
  The TwixT profile defines no standard policy property, but SGF
  FF[4] explicitly permits private properties: "Everybody is free to
  define additional, private properties", which "may use one of the
  value types defined in this document or define their own value
  type", and unknown properties "should be preserved". A standard
  general-purpose property V already carries a real-valued node score
  across all games. A producer could therefore publish visit
  distributions in SGF, in a sidecar, or in any other format entirely.

  WITHDRAWN: "no corpus carries pi because the format cannot
  represent it". That converted an absence in one profile into a
  universal impossibility. The defensible claim is narrower and is
  the one this report now makes: NO SURVEYED SOURCE PUBLISHES PI.
