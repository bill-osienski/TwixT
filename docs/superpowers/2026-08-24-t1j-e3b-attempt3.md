## 1 — The serialized legal-map width is now compared

`parse_legal_bits` requires **exactly `BOARD_N**2` = 576** characters, all binary, and raises
otherwise. `parse_dump` routes every `LEGAL` line through it.

The control is demonstrably **not vacuous**, and the self-test says so in the artifact rather than
asserting it here:

```
PASS  real dump carries the full 576-bit legal map on all 4 legal lines
      (truncation would drop up to 24 trailing bits and decode to the IDENTICAL set: True
       — so only the width check can reject it)
PASS  TRUNCATED legal serialization rejected   [legal map is 552 bits, expected exactly 576]
PASS  EXTENDED  legal serialization rejected   [legal map is 577 bits, expected exactly 576]
```

Both controls tamper with the **raw process stdout**, not with a parsed object, so they exercise the
parser rather than a data class. 24 bits is the full `x=23` column, forbidden to Y on an empty
board — exactly the "up to 24" the review predicted. Four more unit tests cover the same ground
without Java: full-width round trip, truncated-but-identical-set, extended, and non-binary.

## 2 — The Java sources ship, and the run compiled from them

Committed under **`scripts/GPU/alphazero/t1j_java/`**:

| path | role |
|---|---|
| `net/schwagereit/t1j/E3bDump.java` | the state dumper `replay()` invokes |

| `e2probe/ScratchPrefsFactory.java` | the isolated factory selected before any T1j class loads |

`t1j_adapter.compile_helper(javac, jar, out_dir)` builds from exactly those paths and raises if any
is missing. **The qualification run compiled through the adapter itself**, not through a hand-written
`javac` line, and the transcript records each compile input's sha256 as it was read.

`A6b_compile_input_binding.txt` then binds those three digests **strictly** — 64-hex, absolute path
inside the repo, equal to the file on disk **and** to the digest `A6` records — with negative
controls for an all-zero digest and a single flipped character. All three match.

> **Correction, recorded rather than tidied away.** My first cut of that cross-check was a loose
> `grep` for the digest anywhere in `A6`, and it reported `MATCH 7` — matching the character `7`
> from a prose line, not a hash. The rewrite that replaced it then failed all three rows because I
> had built the lookup dict **hash→path instead of path→hash**. The data was correct throughout;
> both faults were in my checking. `A6c_bind_compile_inputs.py.txt` is the version that ran.

**What "independently runnable" does and does not mean.** Nothing has to be *reconstructed*: the
repository now contains every source the adapter needs. It still requires **a JDK and the T1j jar
from outside the repository** — deliberately, since T1j is GPL-3.0 and is neither modified nor
redistributed here. `E3bDump.java` carries a provenance header saying so: it is original code
containing no T1j source, declaring T1j's package because the members it needs are package-visible.

  board-full path, no swap, no non-24×24 board.

  qualified adapter yields an **ordering**, not a placement.
